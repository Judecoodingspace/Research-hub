## 一、核心时间参数定义

| 参数 | 定义 | 谁决定 | 当前值 | 对应审稿意见 |
|------|------|--------|--------|-------------|
| **Δt** | 时隙长度（VT Agent 决策周期） | 系统设计（LTE-V2X 子帧） | 1 ms | — |
| **T_upd** | BS 广播周期（DQI/θ/P_cap 更新间隔）；同时也是功率调整延迟 | 工程选择 | 10 slots = 10 ms | R1-C8, R1-C11 |
| **T_stat** | 统计描述符（DQI/θ）的自然相干时间——在此窗口内底层物理量不发生有意义变化 | 环境物理约束 | ~100 slots = 100 ms | R1-C11 |
| **约束** | T_upd ≪ T_stat | — | 10 ms ≪ 100 ms ✓ | — |

### T_stat 不是可调参数

T_stat 的本质是**环境决定的物理上限**，不是工程参数。其推导依据：

| 底层物理量 | 变化机制 | 变化时间尺度 | 对 DQI/θ 的影响 |
|-----------|---------|-------------|----------------|
| 路径损耗 PL(d) | VT 移动 10m 产生约 3dB 变化（5.9GHz UMi 模型） | 120km/h 下 ≈ 300ms | DQI 中的 SNR/RSS 项 |
| 阴影衰落 | 空间相关距离 ≈ 10-50m | 300ms-1.5s | DQI 中的 RSS 项 |
| PU 占用状态 | 两状态 Markov, p01=p10=0.2 | 平均占用/空闲时长 ≈ 5 slots (5ms) | θ 预测概率的统计可靠性 |
| PU 发射功率档位 | 长期 RSS 聚类（K-means） | 秒级 | Ψ 的估计值 |

**最紧约束**：PU 占用模式——单个 slot 状态切换快（~5ms），但 DQI 和 θ 捕捉的是统计规律，其在 ~100ms 窗口内可靠性稳定。因此取 T_stat ≈ 100ms 作为保守估计。

### T_upd < T_stat 的工程含义

```
T_stat (≈100ms) = 描述符自然有效的物理上限
        ↓
T_upd (10ms)    = 我们主动选择的广播周期
        ↓
T_upd/T_stat = 1/10 → 在 T_stat 窗口内广播 10 次
        ↓
每个时隙 VT 使用的广播缓存最多过时 9ms ≪ 100ms
        ↓
结论：DQI/θ 永不过期——T_upd ≪ T_stat 保证描述符永远在有效窗口内
```

## 三、三组变量的时间尺度分层

```
┌──────────────────────────────────────────────────────────────┐
│                      时间尺度分层                             │
│                                                              │
│  最快（每时隙 Δt = 1ms）：                                   │
│    δ_t (瞬时感知) — VT 本地采集，每时隙更新                    │
│    A_t (动作)     — Agent 每时隙决策                          │
│    r_t (奖励)     — 每时隙计算                                │
│    P_actual       — 每时隙根据模式选择功率来源（见§五）        │
│                                                              │
│  中等（每 T_upd = 10ms）：                                   │
│    DQI_t, θ_t, P_cap_t — BS 计算后广播，VT 缓存到下一次更新   │
│                                                              │
│  最慢（T_stat ≈ 100ms——物理相干时间内）：                     │
│    DQI 和 θ 的底层统计模式几乎不变                             │
│    路径损耗 ĝ（取决于空间位置，米级变化，对应百毫秒级）         │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 变量新旧程度（staleness）分析

| 距上次广播 | 陈旧度 | DQI/θ 可靠性 | P_cap 可靠性 |
|-----------|--------|-------------|-------------|
| 0 slot | 0ms | 最新 | 最新（ĝ 基于当前 VT 位置） |
| 5 slots | 5ms | 几乎不变 | ĝ 基于 0.17m 外的位置（120km/h） |
| 9 slots | 9ms | 几乎不变 | ĝ 基于 0.3m 外的位置 |
| 10 slots | 触发新广播 | 刷新 | 刷新 |
| 19 slots | 19ms | 接近 T_stat 边界 | ĝ 基于 0.63m 外的位置 → 陈旧风险 |

因为 T_upd (10ms) ≪ T_stat (≈100ms)，最陈旧时隙（t=9，距广播 9ms）的描述符仍在有效窗口内。**T_upd 敏感性实验本质上就是在量化 staleness 的影响**。

## 四、BS 广播与 VT Agent 决策的关系

### 核心原则：BS 广播约束条件，VT Agent 在约束下优化决策

```
┌──────────────────────────────────────────────────────────────────┐
│                        VT Agent (每时隙)                          │
│                                                                   │
│  State S_t = {δ_t(瞬时感知), DQI_last(缓存), θ_last(缓存)}        │
│                                                                   │
│  Action A_t = (信道 m, 模式 mode)                                 │
│    ├─ mode = overlay  → P_actual = P_max（硬件常数，不需BS）       │
│    └─ mode = underlay → P_actual = P_cap_last（BS 广播缓存）       │
│                                                                   │
│  Reward r_t = f(mode, 信道质量, 吞吐量, 是否违规)                  │
│    ├─ overlay: 质量优先(Γ·DQI), 零干扰惩罚                         │
│    └─ underlay: sigmoid(Ψ − ĝ·κ·P) → 合规有赏, 超标硬趋 −κ        │
│                                                                   │
└──────────────────────────┬───────────────────────────────────────┘
                           │
         每 T_upd 时隙 BS 广播: {DQI, θ, P_cap}
                           │
┌──────────────────────────▼───────────────────────────────────────┐
│                     BS 侧 (每 T_upd)                               │
│                                                                   │
│  输入: VT 位置 (V2X CAM 10Hz) + PU 注册位置                        │
│       PU 功率档位 (RSS 聚类)                                       │
│       PU QoS 需求 C_min → 闭式导出 Ψ                               │
│                                                                   │
│  计算: d(VT, PU) → PL(d) → ĝ = 1/PL(d)                            │
│       P_cap = min(P_max, Ψ / (ĝ · κ))                              │
│                                                                   │
│  广播: Φ'_t (DQI), θ_t (预测概率), P_cap_t (功率上限)              │
│                                                                   │
└──────────────────────────────────────────────────────────────────┘
```

**两者不在同一时间尺度上运行**：

| | 谁决定 | 何时决定 | 决策频率 |
|------|--------|--------|------|
| 接入模式（overlay/underlay） | VT Agent (ESN-DDQN) | 每时隙 | 每 Δt = 1ms |
| 信道选择（m ∈ {1..M}） | VT Agent (ESN-DDQN) | 每时隙 | 每 Δt = 1ms |
| Underlay 发射功率上限 | BS 广播 P_cap（VT 自动执行） | BS 计算周期 | 每 T_upd = 10ms |
| Overlay 发射功率 | 恒为 P_max（硬件常数） | — | — |

## 五、为什么功率不进入 RL 动作空间

### 对比：两种建模方式

| 维度 | 方案 A：功率入 RL 动作空间（如 Liu 2024） | 方案 B：BS 硬约束功率上限（当前方案） |
|------|------------------------------------------|--------------------------------------|
| **动作空间** | (信道, 模式, 功率档位) → 组合爆炸 | (信道, 模式) → 紧凑 |
| **收敛速度** | 更慢——需探索功率维度 | 更快——功率由物理约束锁定 |
| **PU 保护保证** | 软保证——靠 reward 惩罚引导，可能被 reward-hack | **硬保证**——物理上限不可逾越 |
| **对 ĝ 的依赖** | 需要 ĝ 算 reward（在线暴露不可知信道信息） | 需要 ĝ 算 P_cap（BS 侧计算，VT 不可见） |
| **部署可行性** | Agent 需要知道 SU-PU 信道增益（V2X 中不可行） | P_cap 广播即可——Agent 无需知道 ĝ |
| **"为什么不能用更简单方案"** | Agent 学功率 → 更多样本、更慢收敛 → 需论证为何值得 | 物理约束自动施加 → 零学习成本，场景约束天然支持 |

### 方案 B 的场景论证（Scenario → Algorithm Mapping）

| 场景特征 | 引发的技术需求 | 选择的设计 | 必要性强度 |
|----------|--------------|-----------|-----------|
| SU-PU 信道不可观测 | ĝ 仅是保守代理，非精确值 | 不让 Agent 基于不准的 ĝ 学精细功率 | **强** |
| PU 保护是硬约束 | 不可因 RL 探索而违规 | 功率上限由物理层保证，不由 reward 引导 | **强** |
| CVN 高移动性 | 收敛速度是瓶颈 | 缩减动作空间（去掉功率维度）加速训练 | **强** |
| 路径损耗变化慢（米级） | P_cap 在 ms 级不变 | 开环前馈即可，无需闭环迭代 | **强** |

## 六、Overlay ↔ Underlay 切换时的功率调整

### 切换是瞬时的、零延迟的、不需 BS 参与的

```
═══════════════════════════════════════════════════════════════
时隙 t=7: Agent 决策 underlay, 使用 P_cap_last = 0.4 mW (受限)
时隙 t=8: Agent 决策 overlay,  使用 P_max     = 1.0 mW (全功率)
═══════════════════════════════════════════════════════════════
```

**不需要等 BS 下一次广播**。原因：

| 模式 | 功率来源 | 是否需要 BS 当前广播 | 切换延迟 |
|------|---------|---------------------|---------|
| Overlay | P_max（VT 硬件已知常数） | 不需要 | 0 |
| Underlay | P_cap_last（BS 上次广播的缓存值） | 不需要——缓存即可 | 0 |
| 不接入 | 0 | 不需要 | 0 |

### 每个时隙的功率决策树

```
Agent 输出 A_t = (信道 j, 模式 mode)

if mode == overlay:
    if δ_t[j] == idle:        ← 正常情况
        P = P_max             ← 直接用硬件上限
    else:                     ← Agent 犯错（选了 busy 信道做 overlay）
        P = P_max             ← 仍全功率，但 reward 会惩罚此行为

if mode == underlay:
    P = P_cap_last            ← 用上次 BS 广播缓存值

if mode == 不接入:
    P = 0
```

**Overlay 可以用 P_max 的原因**：Overlay 模式只选择感知为空闲（δ=idle）的信道，空闲信道上无 PU → 无 SU-PU 干扰风险 → 功率上限仅受 VT 硬件限制。

### VT 功率切换延迟总结

| 切换方向 | 延迟 | 原因 |
|----------|------|------|
| Overlay → Underlay | 0 ms | P_cap_last 始终在缓存中，即刻可用 |
| Underlay → Overlay | 0 ms | P_max 是常量，不需等任何外部信息 |
| Underlay 功率上限刷新 | 最多 T_upd = 10 ms | 需等下一次 BS 广播 |

## 七、通信开销量化

### 计算

| 项目 | 值 |
|------|-----|
| 每信道载荷 | DQI (8bit) + θ (8bit) + P_cap (8bit) = **3 bytes** |
| M=3 信道 | 9 bytes/广播 |
| M=5 信道 | 15 bytes/广播 |
| M=10 信道（扩展场景） | 30 bytes/广播 |
| 广播频率 | 1/T_upd = 1/(10ms) = 100 Hz |
| 总开销（M=5） | 15 bytes × 100/s = **1.5 kB/s = 12 kbps** |
| 信道容量参考（200kHz, ~2bps/Hz） | ≈ 400 kbps |
| 开销占比（M=5） | 12/400 ≈ **3%** |
| 开销占比（M=10） | 24/400 ≈ **6%** |

**结论**：广播开销占比 <3% (M=5) 至 <6% (M=10)，在 V2X 控制信道中完全可接受。

## 八、实验验证方案

### 实验 1：T_upd 敏感性（= 描述符陈旧度敏感性）

| 参数 | 值 |
|------|-----|
| 扫参范围 | T_upd ∈ {1, 5, 10, 20} slots |
| 固定参数 | Δt = 1ms, κ = 2, M<N + M>N |
| 输出指标 | VT 吞吐量, PU 吞吐量, PU 干扰违规率 |
| 预期结果 | T_upd ≤ 10 时三指标稳定；T_upd=20 时退化（最陈旧描述符 19ms 接近 T_stat 边界） |

**物理含义**：更大的 T_upd → VT 使用的描述符平均更陈旧 → 当陈旧度接近 T_stat 时，ĝ 过时导致功率上限过度保守（VT 吞吐量↓）或违规率↑。

### 实验 2：衰落裕量 κ 敏感性

| 参数 | 值 |
|------|-----|
| 扫参范围 | κ ∈ {1, √2, 2, 4, 8}（对应 0, 1.5, 3, 6, 9 dB） |
| 固定参数 | Δt = 1ms, T_upd = 10, M<N |
| 输出指标 | PU 违规率, VT underlay 吞吐量, underlay 动作选择比例 |
| 预期结果 | κ↑ → 违规率↓ (保护更强) 但 underlay 吞吐量↓ (过度保守)；κ↓ → 反之；存在 κ ∈ [2,4] 的 sweet spot |

**物理含义**：κ 吸收小尺度衰落不确定性和 ĝ 陈旧残余误差。κ 与 T_upd 互补——T_upd 小 → 位置准 → κ 可小；T_upd 大 → 位置旧 → κ 需大。

## 九、对审稿意见的回应映射

### R1-C8（Underlay 功率控制机制）

| 子问题 | 答案 |
|--------|------|
| 有无控制回路？ | 无。采用**开环前馈闭式上限**——BS 预先计算 P_cap，VT 即时应用。不需要闭环迭代，因为 SU-PU 链路不可观测 + 路径损耗在 T_upd 内不变。 |
| 离散功率级别？ | 不是。采用**连续闭式上限** `P = min(P_max, Ψ/(ĝ·κ))`，比离散档位更精细。连续值可映射到功放最接近步进值（向下取——因为是上界，更低功率更安全）。 |
| 闭式更新？ | 是。`P_cap = min(P_max, Ψ/(ĝ·κ))` 是闭式表达式，无需迭代求解。 |
| 功率调整频率？ | 每 T_upd = 10ms（BS 重算 + 广播）。 |
| 功率调整延迟？ | = T_upd = 10ms。但模式切换（overlay↔underlay）是 0ms 延迟——因为 overlay 用 P_max 常量，underlay 用缓存 P_cap_last，都不需要等 BS。 |

### R1-C11（通信开销与陈旧度敏感性）

| 子问题 | 答案 |
|--------|------|
| 广播通信开销？ | 15 bytes/广播 (M=5)，1.5 kB/s ≈ 12 kbps，<3% 信道容量。 |
| 对 T_upd/T_stat 的敏感性？ | T_stat ≈ 100ms 从环境物理推导（路径损耗空间尺度 + PU 占用统计），不是可调参数。T_upd 敏感性见实验 1——≤10ms 稳定，≥20ms 退化。 |
| 对描述符陈旧度的敏感性？ | 实验 1（T_upd 扫描）直接量化 staleness 影响。最陈旧时隙（距广播 9ms）≪ T_stat (100ms)，性能不受影响。 |

## 十、关键设计选择总览

| 设计选择 | 方案 | 论证逻辑链 |
|----------|------|-----------|
| 功率不入 RL 动作空间 | BS 硬约束功率上限 | SU-PU 信道不可观测 → ĝ 仅是代理 → 不应让 Agent 基于不准信号学功率 → 物理上限硬保证 > 软 reward 引导 |
| 开环前馈而非闭环迭代 | 闭式 P_cap 表达式 | 路径损耗变化慢（米级/百毫秒） → T_upd 内近似准静态 → 闭环反馈信道不可用 → 开环足够 |
| 连续上限而非离散档位 | `min(P_max, Ψ/(ĝ·κ))` | 连续值 → 无量化损失；可向下取到功放档位 → 不破坏干扰保证（因为是上界） |
| T_upd = 10ms | 设计选择 | 远小于 T_stat (≈100ms) → 描述符永不过期；开销 <3% 可接受 |
| T_stat ≈ 100ms | 环境物理约束 | 路径损耗 ~300ms/10m + PU 统计 ~50-100ms → 取保守值 100ms |
| 衰落裕量 κ | 保守缓冲 | 吸收小尺度衰落 + 模型误差 + ĝ 陈旧残余；与 T_upd 互补 |
