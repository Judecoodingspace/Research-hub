# 面向多无人机任务导向通信的初步 Gap Map

## 说明
- 该 gap map 仅基于两篇样本文献：Ren 2024 与 Guo 2026。
- 因样本量有限，以下判断应视为“初步 gap 判断”，用于形成研究切入方向，而不是宣称已经穷尽相关工作。

## 1. 当前已有工作主要覆盖了什么
- 已有工作开始从数据导向通信转向任务导向/语义导向通信。
- Ren 2024 主要覆盖“多模态任务语义如何支撑 UAV 任务执行”，把任务执行重新表述为语义识别与语用执行。
- Guo 2026 主要覆盖“语义增强后如何做任务导向资源优化”，把多模态语义通信与轨迹规划、资源管理联动起来。
- 从这两篇可以看出，当前方向已经不再满足于纯重建质量，而开始关注任务收益、语义重要性和系统资源约束。

## 2. 它们共同忽略了什么
- 共同忽略了显式的多 UAV 协同机制。
- 共同没有清晰展示多 UAV 之间的任务分工、视角互补、跨节点资源竞争与协同收益建模。
- 共同没有明确处理异构算力下的动态切分、跨节点协同推理和端-边-空分层执行。
- 共同没有把采集、传输、推理三者真正闭环起来：Ren 更偏语义建模，Guo 虽加入轨迹和资源优化，但仍未清楚覆盖协同推理与多视角冗余压缩。
- 虽然两篇都涉及多模态，但“统一任务语义空间如何跨节点共享与更新”仍不充分可证。

## 3. 为什么这些忽略对多无人机任务导向通信是关键问题
- 在多 UAV 场景中，问题的难点不只是“每个节点传什么”，而是“多个节点分别采什么、传什么、算什么，以及这些决策如何共同服务同一个任务目标”。
- 如果没有显式协同建模，多视角数据很容易产生重复传输与重复推理，带来额外带宽和能耗浪费。
- 如果没有异构算力与动态切分建模，就很难回答资源受限 UAV 与潜在边缘节点之间的任务分工问题。
- 如果路径规划和视角选择不与下游语义推理联动，系统可能获得大量数据，却没有带来有效任务收益提升。

## 4. 当前最有价值的研究空白

### Gap A：从单节点语义决策走向多 UAV 协同任务语义决策
- 当前已有工作主要能说明“任务语义重要”，但还没有充分说明“多个 UAV 之间如何围绕同一任务共享语义、分配采集视角和避免冗余”。
- 这个 gap 有意义，因为多 UAV 系统的优势本来就来自协同和多视角互补，如果语义通信仍按单节点思路设计，会丢掉核心系统收益。
- 这个 gap 可建模，因为可以把 UAV 任务分工、视角选择、语义重要性和协同收益写进联合优化目标或多智能体决策过程。
- 这个 gap 可验证，因为可以比较单 UAV / 独立多 UAV / 协同多 UAV 三类方案在任务成功率、时延、能耗和协同收益上的差异。

### Gap B：从高层资源管理走向异构算力下的感知-通信-推理联合优化
- 当前已有工作虽然开始做语义感知资源优化，但尚未清楚处理异构算力、动态切分和跨节点协同推理。
- 这个 gap 有意义，因为在真实系统中，语义价值、传输代价和计算代价是联动的，脱离切分与执行位置的资源调度往往不完整。
- 这个 gap 可建模，因为可以把切分点、卸载比例、带宽分配、算力分配和任务时延统一纳入约束优化或强化学习框架。
- 这个 gap 可验证，因为可以用任务精度、端到端时延、能耗、带宽占用和推理稳定性做联合评测。

### Gap C：从静态多模态融合走向多视角采集-传输-推理耦合规划
- 当前已有工作把多模态引入了语义通信，但并未充分展示多视角 UAV 采集路径如何与下游语义价值耦合。
- 这个 gap 有意义，因为多无人机系统的关键差异之一就是可通过不同轨迹获得互补信息，而不是只在已有输入上做融合。
- 这个 gap 可建模，因为可以把轨迹、视角覆盖质量、语义重要性、冗余度和传输/推理代价联合定义为优化目标。
- 这个 gap 可验证，因为可以通过不同轨迹策略下的任务完成效果、视角互补收益和通信负载进行定量比较。

## 5. 面向当前主线的建议切入表述
可以把当前研究切入点表述为：

“现有 UAV 多模态语义通信工作已经开始从数据传输转向任务语义表达，并进一步涉及资源调度与轨迹优化；但这些工作大多仍缺少面向多 UAV 协同场景的统一建模，尚未把多视角采集、语义传输、异构算力下的协同推理与动态资源分配纳入同一任务导向闭环。因此，面向多无人机任务导向通信，构建兼顾语义价值、协同收益与系统资源约束的全链路联合优化框架，具有明确的问题意义、建模空间和实验可验证性。”

## 6. 后续补强建议
- 若后续补齐 notes 或可稳定解析 PDF，应优先确认两篇论文是否默认单 UAV、其 QoE/目标函数具体定义、以及是否存在真实部署或更细粒度对比实验。
- 若后续继续扩样，建议优先加入“多 UAV 协同推理”“动态模型切分”“视角规划与任务完成率联动”三类论文，以验证上述 gap 是否具有更强共性。
