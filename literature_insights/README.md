# Literature Insights Bank

记录已阅读文献对研究工作的启发和优化建议。与 `papercard/`、`compare/`、`gap_map/` 的区别：

| 文件夹 | 内容 |
|--------|------|
| `papercard/` | 论文本身的结构化分析（"这篇论文做了什么"） |
| `compare/` | 多篇论文的横向比较（"它们之间的关系是什么"） |
| `gap_map/` | 研究空白和切入点（"还有什么没做"） |
| **`literature_insights/`** | **文献对当前研究的具体启发（"这篇论文告诉我该怎么做"）** |
| `writing_support/` | 论文写作支撑材料 |

## 组织形式

```
literature_insights/
  └── <研究项目标识>/            # 如 paper3-conditional-collaboration
        ├── index.md             # 该研究项目的所有启发汇总
        └── <AuthorYear_Keyword>.md  # 单篇文献的启发详情
```
